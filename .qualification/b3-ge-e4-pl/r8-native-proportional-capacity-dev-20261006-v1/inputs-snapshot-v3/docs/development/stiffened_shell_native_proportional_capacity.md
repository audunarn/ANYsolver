## Durable public callback and failure contract

`proportional_workflow` accepts the explicit checkpoint bytes or path. File,
checksum, model, generation, controller, restore and programming errors propagate.
It constructs a fresh owner, preflights/restores, validates the actual prefix,
and streams the restored origin before any arc call. There is no ordinary solve.

After each accepted arc state, public `on_accepted` runs after atomic publication.
Source inspection confirms that public `recover` and `checkpoint` use the accepted
snapshot/commit lock; checkpoint has no state-writer rejection. The example reads
the actual committed checkpoint **inside this callback**, verifies callback versus
complete public recovery, and passes `on_state` an independently owned packet:

```text
observation (complete public state and physical diagnostics)
checkpoint_bytes (actual immutable bytes)
checkpoint_sha256, checkpoint_size_bytes
generation, accepted_status
```

The example creates no output files. A future authorized supervisor may write
each packet's bytes and observation to unique binary/JSONL evidence before a
process-tree timeout. Streaming ownership tests check that user mutation cannot
change report witnesses and writer errors propagate. The separate `on_accepted`
callback receives another detached result for steering cooperative cancellation.
Observer exceptions, even exceptions using a solver-failure class, propagate.
No callback-driven borrowed state is retained.

Only exact `ArcSelectionFailure`, `FiniteIncrementFailure` and cooperative
`SolveCancelled` from the continuation itself become terminal reports. Attempts,
reasons and actual recovered status/generation are retained. A pre-cancellation
or first-trial failure can leave the actual ordinary prefix status `completed`;
an arc prefix usually recovers as `accepted_prefix`. Neither means that the
requested arc count completed. Noncompleted public returns report
`incomplete_arc_return`; missing accepted delivery or checkpoint mismatch raises
an error. A final actual checkpoint must match the last delivered packet.
