# Candidate evidence and quickstart

Start with [the durable status/restart handoff](../GENERAL_CONTACT_CANDIDATE_HANDOFF_20261019.md).
The files in this directory are frozen copies of the measured 2026-10-19 bundle
records; paths, no-commit statements and authority remaining in those historical
records describe the time they were produced. ROOT_CANDIDATE_ACCEPTANCE closes
the allowance. They do not qualify a later merge automatically.

For installation use the immutable ZIP linked in the handoff. Its relative
README/examples/wheelhouse form the runnable distribution; this compact Git copy
does not duplicate binaries or all raw evidence. See BUNDLE_README.md for the
original recipe, ACCURACY.md, KNOWN_LIMITATIONS.md and MEASURED_SUPPORT.json for
claims, and INTEGRATION.json for the subsequent local Git merge/check disposition.
The manifest names files inside the original ZIP, not this compact directory.
