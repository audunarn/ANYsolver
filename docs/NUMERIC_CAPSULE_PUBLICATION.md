# Numeric capsule publication

`export_recovery_capsule` and `export_recovery_capsule_to_sink` accept the
keyword-only `recovery_execution='auto'|'records'`. `records` consumes the
ordinary detailed dictionary output and is the compatibility comparator.
`auto` publishes component rows directly for the existing certified-library
route when the complete block was reconstructed and no envelope transaction
is active. Other routes, source disagreements, certification fallbacks and
envelope recovery retain the original recovery path and actual route labels.
Ordinary `PreparedStaticResponseEvaluator.iter_batches` is unchanged.

The numeric path runs at the original recovery stage after actual load
construction, solve and full-state backward-error certification. It does not
certify cases offline or change source agreement, eligibility or tolerances.
It retains complete original element-vector schemas, original active-column
order, baseline application and vector right-hand sides. A grouped independent
F-plane candidate is compared, for every element and case, against the actual
original per-element operation using float64 bits. Any difference uses the
original values. This is an unconditional oracle, not an inference from a few
preparation probes. Signed zero also participates in exporter field parity.

Derived measures use the existing source expressions, including beam scalar
exponentiation and original principal tensor shapes. Component layouts preserve
native samples, scalar/array distinctions and principal-rank descriptors.
Displacements are extracted from the actual full solution. Requested reactions
use the existing actual `Ku-F` diagnostics and selected-reaction service.
Source-owned model/recovery metadata and case identities are unchanged.

No case-by-element output dictionaries are retained on the numeric path. Fixed
layouts are prepared once; at most 64 element vectors are processed together,
and each active batch retains complete component rows. The original resource
policy also accounts for retained layouts, batch rows and numeric workspace
before allocation. Temporary source field mappings exist only while extracting
one element's derived measures. Requested force diagnostics and per-case
metadata remain the existing dictionaries; this change does not solve their
possible output-size duplication. The mapping-returning exporter remains
output-sized; use the four-callback sink for bounded incremental storage.

Original source/ownership guards surround numeric publication. Caller token
observations occur outside owned recovery scopes, with source authority
rechecked before using their results. Interrupted or refused exports preserve
the existing optional `capsule_failed` notification and never report a completed
capsule. All numerical arrays supplied to sink callbacks remain immutable.

Focused evidence compares complete auto and records capsules bytewise for beam2,
generalized beam3, rotated S3 pressure, principal-only selections, native
layouts, sparse/reversed/empty and large coefficients, reactions, displacements,
canonical fallback, envelopes and refusal/mutation/cancellation paths. This is
implementation evidence, not additional scientific qualification.

The first development-scale physical fixture used 1000 independent axial beam
members, 20 disjoint actual load patterns, a nonzero baseline and 100 dense
combinations. Complete capsules matched bytewise. The precise process wall was
95.6027006 seconds: preparation 70.6209766, records export 3.8687194 and initial
numeric export 19.2730551 seconds. The latter included subsequently removed
unnecessary per-tile authority checks when no caller token was present. Preserve
this initial measurement; it does not demonstrate a speed improvement. Its
evidence is `producer-numeric-evidence/test-1791830008599838000` in the authorized
workspace. No 100k-element or 10k-combination producer was executed here, and
no general shell or all-output scale claim follows from this axial fixture.

After that compatible observation-scope repair, the one authorized changed-input
repeat passed in 80.1140125 seconds process wall: preparation 71.2752333,
records export 3.8890258 and numeric export 2.9801557 seconds. All 100 cases were
portable, with 14 descriptors and no explicit overrides or differing grouped
kernel tiles. The original oracle took 0.3282961 seconds, grouped trials
0.2273334, source measures 0.4741175, field publication 0.0636508 and nodal
extraction 0.0412051. This is one measured axial fixture, not a universal speed
ratio. Preparation remains an unresolved independent scaling question. Evidence:
`producer-numeric-evidence/test-1791830278572643300`.
