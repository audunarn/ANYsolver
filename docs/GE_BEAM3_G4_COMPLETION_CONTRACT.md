# GE Beam3 G4 material-state completion contract

## Scope

This successor closes only general-static material/state obligations S19--S24.
It composes the already accepted G4a heterogeneous station transaction with the
existing retained generalized, physical-fibre, arc-length and beam--shell-joint
owners. It introduces no new beam or shell mechanics, public route, default,
section equation, tolerance, or production claim.

## Ownership and publication

One checkpoint-chain owner binds the immutable graph, formulation, section-law,
constraint, load, control, provenance and accepted-epoch identities. A step is
published only after every heterogeneous station has completed trial and prepare.
Failure before publication discards the whole proposal; failure after publication
retains the new accepted epoch. Constitutive origins always equal the preceding
accepted histories.

## Restart

The checkpoint is strict canonical JSON with an external SHA-256 authority. It
stores no executable class name and restores no state directly. A fresh,
definition-bound owner replays every accepted strain record and must reproduce the
state and physical-recovery hashes exactly. Duplicate keys, nonfinite values,
foreign owners, altered graph/formulation/section/constraint/load/control,
broken predecessor chains, missing records, legacy/cross-family schemas and any
production-qualified claim fail before publication.

## Frozen functional evidence

The bounded gate executes actual connected generalized plastic, connected
physical-fibre, arc-length and beam--shell joint paths in addition to the
heterogeneous transaction. It verifies load/unload/reversal, accepted-origin
linkage, line-search/cutback/cancellation rollback, final-state replay, physical
resultants/work and fibre capability reporting. Resultant-only laws may not invent
fibre stresses.

## Execution and decision

Smoke precedes one complete rehearsal and two fresh formal cycles. Each child is
limited to one numerical-library thread, 24 GiB, 600 seconds and a 120-second
inactivity watchdog; the wave limit is 1,800 seconds. No retry is automatic.
Canonical scientific outputs from the two formal cycles must be byte-identical.

Terminal precedence is:

1. `BLOCKED_GE_BEAM3_G4_PROCESS_OR_EVIDENCE`
2. `NO_GO_GE_BEAM3_G4_STATE_OR_CONTROL`
3. `NO_GO_GE_BEAM3_G4_RESTART_OR_RECOVERY`
4. `PROVISIONAL_GO_GE_BEAM3_G4_GENERAL_STATIC_MATERIAL_STATE_ONLY`

The successful terminal closes S19--S24 and G4 only. G5, public routing,
production qualification, versioning and publication remain open. The production
restriction remains `NO_GO_PRODUCTION_RESTRICTION_UNCHANGED`.
