# D1 near-rim pressure-knot discriminator — development evidence

**Question and fixed inputs.** The independent fixed-structure scalar Q1 oracle
uses the same 32×8 structural grid, load, clamp, physical support (ending at
`y=.9 m`), and 32-interval x pressure grid in both solves. Only one y pressure
knot changes: `.895 → .900 m`; the other y knots remain
`[0,.2,.4,.6,.75,.825,.875,1]`. This is a development comparison, not a
coupled shell qualification or a pressure-space acceptance run.

The [parameterized probe](../../scripts/general_contact_d1_fixed_structure_pressure_probe.py)
ran against solver source `a306432d626f0c717f4a7ed425a21bef3cfac1c4` and
independent oracle SHA-256
`9cfa980753f094a8373661e70ccdb55f2634894b3b02566efee76d00817991b3`.
The [raw result](d1_rim_knot_a306432d_20260928.json) binds the probe and
saved-input SHA-256. Both PDAS solves passed their equilibrium and KKT checks.
The active work columns, formed from each solved active set, were full rank
(96/96 and 84/84; minimum normalized singular ratios `.1093` and `.1108`).
Minimum independently represented physical gaps were `−1.79e−8` and
`−4.11e−8 m`, respectively.

| Moved versus matching pressure knot | Relative difference |
|---|---:|
| Common 8×9 bin force, L1 / L2 | 0.1817% / 0.3113% |
| Rim-band integrated force | 0.3660% |
| Total reaction | 0.00537% |
| Physical-support pressure L2 | 70.10% |
| Regular-area pressure L2, `0≤y≤.8` | 0.7789% |
| Rim pressure L2, `.8≤y≤.9` | 77.31% |

The pressure change is concentrated in the last support band for this
single-knot perturbation. It does not explain the earlier 16→32 x-refinement
change throughout the regular area, prove mesh-uniform stability, or justify
changing production pressure geometry. The supported mode count changes
because a knot at the physical support edge has no supported neighbor above
it. No exact local active work null was found.

The first bounded invocation stopped at an auxiliary **probe** check: a
separately solved scaled-QP replay selected a different active set from the
PDAS field. Its [failure log](../../reports/d1_rim_knot_run_a306432d_20260928.log)
and [resource record](d1_rim_knot_resource_failed_a306432d_20260928.json)
are retained, with a [versioned log copy](d1_rim_knot_probe_failure_a306432d_20260928.log).
The rank check was corrected to inspect the already certified
PDAS solution directly; no production source or mechanical input changed.
The successful [bounded run](d1_rim_knot_resource_passed_a306432d_20260928.json)
took 1.04 s and 74.04 MB peak process-tree memory, within 180 s / 1 GB.
Three focused analytical field-comparison tests passed, including exact
integration over a clipped y band.

**Decision.** Keep the fine Q1 production candidate and its original pressure
stability gate. The physical rim is a sensitive pressure-representation
location, while integrated reactions are much less sensitive in this fixture.
Use the existing common-bin and active-rank evidence for their bounded claims;
do not turn this result into D1 acceptance or launch a larger coupled solve
without a discriminating mechanics and resource hypothesis.
