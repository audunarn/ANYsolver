# Free source-director contact press — bounded D1 development record

The delivered four-Q4/two-S3 deformable-target cycle fixes every source rotation. This experiment kept its material, geometry, Q1 pressure basis, monolithic enforcement, normal law and two-S3 target, and released source `ry` to test whether an ordinary coupled press could exercise source-director work. It is development evidence, not D1 acceptance.

**Unrestrained `ry` exposes a genuine mechanism.** With `ry` free at every source node, the original two-step 0.3 N path exhausted semismooth iterations before accepting a step (104.35 s, 415.33 MB). A contact-free predictor finds a scaled minimum stiffness eigenvalue of 5.08e−16. An explicit infinitesimal rigid rotation about the source left edge satisfies the constraints exactly and has normalized stiffness energy −3.42e−17 and reduced-force ratio 1.30e−16. The solver's iteration failure is not evidence of a bad contact derivative in this singular fixture.

**Physical cantilever support removes the mechanism.** Fixing `ry` only at the two left-edge source support nodes leaves eight source director coordinates free. The constrained scaled stiffness minimum becomes 3.51e−4. The contact-free predictor at the original 0.15 N first load level gives about 22.5 mrad source rotation and −16.39 mm sampled gap, well beyond the declared 50 µm gap budget; the guided counterpart predicts −6.8 µm. A first 0.0005 N event load was selected from that linear displacement scale. The first attempt was rejected at interface validation because the inherited 0.3 N complementarity force scale exceeded the new path maximum. Setting the explicit scale to 0.0005 N allowed one accepted ordinary monolithic increment in 7.69 s/270.09 MB. It has two active pressure modes, maximum source `ry` 6.98e−5 rad, solver-reported sampled minimum gap −5.31 µm, and maximum unprescribed source-`ry` residual 2.66e−18 N·m. Its largest source contact `ry` couple is only 7.01e−13 N·m, too small to verify meaningful coupled director work. No independent gap oracle was run on this new pose.

**The next 0.05 N waypoint did not equilibrate.** A two-segment path retained the same 0.0005 N first event and then requested 0.05 N, with force scale set to the maximum declared load. It accepted only the first state and stopped at `contact_semismooth_backtracking_failed` after 17.40 s/277.09 MB. The failed iteration's contact diagnostic reports two active modes, equilibrium merit 0.208 and complementarity ratio 9.41e−4; no second physical state was committed. Independent read-only scrutiny of the iteration record found empty trial attempts and a null last trial: the swept-geometry admission returned zero before any line-search candidate. This status does not establish pressure instability or rotational disequilibrium.

**One same-case admission replay identified the rejected gate.** A development-only observer wrapped the unchanged admission method and replayed exactly the 0.0005→0.05 N path in 17.48 s/280.40 MB under the existing 180 s/1 GB cap. At the rejected iteration, the starting conservative gap lower bound was −49.9978348 µm against the −50 µm limit: 2.165 nm of remaining margin. The zero-length starting configuration was admitted. At the smallest tested/allowed step fraction, 2⁻¹⁴, the endpoint lower bound was −50.0025527 µm and the swept bound was −50.1302698 µm. The minimum orientation control remained positive at 0.2499729. Hence even that smallest admitted fraction fails the configured endpoint lower-bound gate; orientation is not the rejecting gate. The lower bound is a conservative numerical certificate, not an independent measurement of physical penetration. The unconstrained proposed direction has norm 0.009828 in mixed solver coordinates. The replay is a causal development diagnostic, not a geometry acceptance certificate or evidence that the 0.05 N equilibrium is unattainable. No solver tolerance, step limit or mechanics changed.

The first replay also failed before mechanics because the local source package was absent from its process environment; the [retained console](d1_free_source_director_admission_setup_failure_20260929.txt) records that setup error.

**Decision.** Stop this load-step branch. The physically supported first event is mechanically consistent but does not exercise a resolvable source contact couple. The 0.05 N continuation reaches the penetration budget during an unaccepted algorithmic iterate; a much smaller admissible fraction could not, by itself, establish convergence. Design a separate eccentric coupled fixture with physical supports and an independently registered response. Use an inclined physical contact normal so source `ry` contributes to normal work, then preflight the contact-free direction and gap before one bounded coupled route. Preserve the guided cycle and all failures; do not infer general solver failure from the singular unrestrained fixture or the rejected 0.05 N path.
