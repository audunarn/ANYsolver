# ANYsolver 0.4.5: bounded B3-GE opt-in release

ANYsolver 0.4.5 publishes the accepted `B3-GE` workflow through the explicit
`b3-ge` selector. Legacy B3 remains the default, and qualified Q4/S3 mechanics
and defaults are unchanged.

The bounded gate validates the immutable G7 contract, confirmation, review,
and status; builds a wheel and source archive; compares every installed runtime
module with the release source; installs the wheel and its declared runtime
dependencies into a fresh target; and confirms installed origin, selector,
name, provenance boundary, and the legacy B3 default. Each child has a
three-minute timeout and the scientific qualification campaigns are not rerun.

The v0.4.4 GitHub publication attempt stopped before PyPI upload because its
isolated installed-wheel probe omitted runtime dependencies. That failed run is
preserved as process evidence. Version 0.4.5 contains the corrected gate and no
mechanics change.

The release source archive excludes research plans, raw evidence, tests,
scripts, reports, caches, and temporary worktrees. The complete pre-cleanup
tree remains available at
`archive/anysolver-pre-0.4.4-development-20260916`.
