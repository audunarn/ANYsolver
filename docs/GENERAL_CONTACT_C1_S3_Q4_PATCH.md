# Mixed S3/Q4 patch contact development route

`S3_Q4_PATCH_GENERAL_NODAL_PRIMAL_MORTAR_PENALTY_STATIC_DEV_V0` admits two qualified S3 V2D source faces against one qualified Q4 target face through the ordinary nonlinear static route. The multi-control path has the distinct `S3_Q4_PATCH_GENERAL_NODAL_MULTI_CONTROL_PENALTY_PATH_DEV_V0` identity. This opt-in route is a development subset, not C1 engineering acceptance.

The source has one nonnegative P1 numerical pressure coefficient per distinct physical material node. Pair support, weighted gap and Gram blocks are assembled across both S3 faces before pressure normalization. The Q4 target keeps its original four-node Q1 geometry. Overlap clipping uses the four target corners projected onto each current S3 plane, while physical target position at each integration point uses the original bilinear Q1 shape. This admits bilinear warped **current** Q4 faces from a planar qualified reference face. It does not admit warped reference Q4 geometry or the separate varying-frame warped formulation.

The Q4 physical-skin adapter uses the formulation's director, declared side and thickness. It maps contact work to the Q4 nodal translations and rotation couples. The public settings `q4_target_weighted_gap_tolerance` (weighted gap, m³) and `maximum_q4_target_integration_triangles` must be declared. The former controls an adaptive quadrature **estimate**, not a proven bound. Exhausting the triangle budget fails the candidate. The result reports this estimate and the integration triangle count. Differentiation uses the full aggregate contact energy with an explicit energy-evaluation cap.

An independent physical-gap gate uses every vertex pair of each declared source–target pair. A swept path bound uses physical corners and Bernstein controls for all four Q4 corner normals. Unresolved paths are cut back or rejected. This bound is conservative and can reject safe configurations. No BVH or automatic pairing is present.

The runnable [general_contact_s3_q4_patch_path.py](../examples/general_contact_s3_q4_patch_path.py) presses, slides 50 mm, opens and recontacts a nonmatching two-S3/one-Q4 pair, then emits a version 2 restart checkpoint. The source example completed all four phases; contact pressure was active in phases 1, 2 and 4, and the open phase had zero contact force. The conservative lower gap reached about −6.93 mm and the reported weighted-gap quadrature estimate stayed below 1.4×10⁻¹⁸ m³. A midpoint checkpoint resumed to the same final displacement in the focused test. Its 20 mm gap tolerance and soft penalty are deliberately permissive development settings. They are not engineering recommendations.

The admitted material is homogeneous isotropic elastic. Friction, projected augmentation, Q4 pressure-side Q1 stability, reference-warped Q4, tight independent gap convergence, large patches, full application adapters and impact remain open. The complete C0–C9 programme remains open.

An isolated wheel built from source commit `7befa69d` reproduced the source example byte for byte. This verifies package inclusion and import routing for this example; it does not promote the profile to independent engineering acceptance or publication.

## Projected normal development profile

`S3_Q4_PATCH_GENERAL_NODAL_PRIMAL_MORTAR_AUGMENTED_STATIC_DEV_V0` uses the same two-S3 source pressure nodes and original bilinear Q4 target geometry with `normal_law="augmented"`. Its multi-control owner has the distinct `S3_Q4_PATCH_GENERAL_AUGMENTED_PATH_DEV_V0` identity. Explicit `normal_stiffness` (Pa/m), `gap_tolerance` (m), `pressure_tolerance` (Pa), Q4 weighted-gap tolerance (m³) and finite integration/differentiation budgets are required. Q4 pressure-source and Q4/Q4 augmented routes remain unadmitted.

At fixed algorithmic multiplier, pressure is projected from each source node's reference weighted gap and support. The contact residual is the weighted-gap virtual work `-sum_i p_i dW_i/dq`; its tangent differentiates the moving overlap, bilinear target position and pressure normalization. A changed overlap support can make this tangent nonsymmetric. The iteration merit is reported separately from physical penalty energy. Projection, opening and restart follow the same nested static path transaction as the S3/S3 augmented development route.

Local checks cover zero-gap lateral work with a held positive multiplier, both-body normal balance, a warped-current Q4 target with force/moment balance and a smooth-branch directional tangent. The four-phase coupled path passed press, 25 mm slide, opening and recontact with multiplier release and restart after opening (`s3-q4-augmented-path1.txt`: 1 passed in 1066.45 s for full, partial and resumed solves). This large development cost is measured, not a performance acceptance. The [projected mixed example](../examples/general_contact_s3_q4_patch_augmented_path.py) completed the same phases: active pressure DOFs 1/1/0/1, zero open force/multiplier, five augmentation passes on initial press and recontact, and version-2 checkpoint. Its conservative lower gap reached −0.7255 mm, with weighted-gap quadrature estimates below 1.1×10⁻¹⁸ m³. The example uses a permissive 20 mm gap budget; neither it nor the soft 1000 Pa/m regularization is an engineering recommendation. Tight independent-gap enforcement, pressure-space convergence, quadrature-versus-differentiation error separation and independent engineering acceptance remain open.

The isolated wheel built from source commit `d8b0de9e` reproduced the projected mixed example byte for byte. This confirms package inclusion and import routing for this development profile; it does not establish engineering acceptance, performance acceptance or publication.
