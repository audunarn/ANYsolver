# Fixed-tool contact arc length (development)

`solve_static_arc_length(..., contact=definition, contact_settings=settings)` adds an explicit `S3_FIXED_TRIANGULATED_RIGID_ARC_PENALTY_DEV_V1` profile. Use `report_general_contact_capability(..., analysis_control="arc_length")` for the actual arc admission. The existing spherical solver, metric, reduction and continuation controls are reused. No-contact restart contract and path fields remain unchanged.

The supported contributor is the existing elastic affine physical-skin S3 fixed planar finite triangulated tool manager, including connected shared-pressure patches. All source/target contributions aggregate before the penalty law; the complete structural plus contact tangent enters the GENERAL sparse factorization and prescribed-path direction `T.T @ (Fref - K @ offset)`. Fixed tools have zero parameter derivative; no pressure/history state is imported. Augmentation, friction, native, moving/free tools, finite rotation, preload, imperfection and seeded histories remain explicitly incomplete/unsupported. No alternate law or algorithm fallback is selected.

Every candidate is certified along both accepted-to-candidate and actual Newton proposal segments by the existing conservative fixed-tool swept service. Uncertified proposals cut back the existing arc radius within its finite controls. Endpoint gap and complete bounded history encoding validate before structural/contact commit. Cancellation before commit and propagating assembly exceptions discard trials and restore the runtime scope. Progress callback exceptions retain the pre-existing observational callback behavior; they are not a propagating rollback API.

Opt-in analysis identity `ANYSOLVER_ARC_CONTACT_RESTART_CONTRACT_V1` binds the complete contributor/settings profile. A namespaced path `contact_state` stores bounded exact-bit inert accepted poses and contact summaries through the existing archive codec, including declared +infinity open-gap markers. Restore replays contributor geometry/sweeps and verifies endpoint identity, structural constraint chart, spherical/step metrics and predictor increments. It is a solver checkpoint, not a new archive owner. Contact-free format remains exact.

`examples/general_contact_arc_length.py` freezes a connected two-S3/nonmatching finite-tool example, k=1e6 N/m^3, physical gap gate50um, three proportional -.05N nodal reference loads, load scaling.01 and initial/min/max increments(2.5e-5,5e-7,2.5e-5). The original .25 increment fixture produced a .249m first displacement and cannot reach this gap domain within its finite retry controls; that NONPASS remains raw. The corrected dimensional fixture changes no mechanical/tolerance/cap input.

Verification compares each accepted point with independent assembled P1 mass/support active-set response plus separately assembled structural K; spherical constraints, physical gap, contact virtual work/tangent and exact prefix/restart are checked. Force and moment balances use separate.15N/.15N*m scales. Existing `step.support_reactions` are raw sums of named generalized DOF components, not moments about an origin; physical support wrenches use constrained per-node residuals and accepted-position cross-force terms. This development subset does not close all C5/C0-C9 requirements or establish engineering acceptance/release.
