Read-only review of the draft manifest and two preparatory helpers on 21 September 2026. No candidate was executed, no registered qualification was consumed, and this review does not accept F03 or G0B.

## Remaining pre-freeze correction

**P1 — unrestricted common-patch pose probe conflicts with the supported native `Context`.** The manifest requires finite-difference common beam/shell rigid and affine fields using `Context.advance`, while the native fixture fixes all six root physical DOFs. `Context.advance` calls `make`, which rejects a displaced or rotated fixed root (`src/anysolver/_ge_beam3_retained_generalized_state.py`, fixed-state validation). Neither a nonzero rigid translation nor a general rigid rotation can be applied to that fixture. Specify a separately constructed *unrestricted native patch fixture* with the same section and trace law, or separate the unrestricted analytic rigid/affine trace check from supported finite-difference probes. Retain the supported fixture and its root boundary for the actual 18-mesh KKT inventory; do not silently skip the common-patch check after the context rejects it. State how beam cell/nodal rotations are assigned for any non-rigid affine field so that its expected relative pose is unambiguous.
