# S3 E4-PL V6W final opt-in qualification composition

V6W is a standard-library-only, nonmechanical composition of the accepted V2D
local, parity, mixed-spatial, eigen, performance, package, restart, batching,
migration, and provenance evidence. It executes no mechanics and builds no new
wheel.

The historical V6P Stage 4A NO-GO, V6Q process block, V6S performance NO-GO,
and first V6V package block remain immutable. Their exact successor evidence is
V6R for the corrected 25-percent spatial decisions, V6T plus V6U for assembly
performance, and corrected V6V for isolated package evidence. No historical
terminal is reclassified.

Run the frozen synthesizer twice into distinct fresh external directories and
require byte-identical canonical outputs. Strict JSON parsing rejects duplicate
keys and nonfinite values. The synthesizer imports only the standard library and
recomputes required predicates from the bound result fields rather than trusting
terminal labels alone.

Terminal precedence:

1. `BLOCKED_E4_PL_S3_V6W_EVIDENCE_OR_REVIEW`
2. `NO_GO_E4_PL_S3_V6W_QUALIFICATION`
3. `PROVISIONAL_GO_E4_PL_S3_V2D_OPT_IN_QUALIFIED`

The successful terminal qualifies only explicit construction through
`e4-pl-s3-v2d` (and its explicit V2D synonym). It does not authorize S3 default
activation, ecosystem routing, release publication, or a Q4 mechanics change.
Q4 remains `e4-pl`; S3 remains `legacy-s3` by default; ANYmesh remains untouched.
