## Physical idealization, signs and work

The declared straight geometry is matched: 1 m long, 0.2 m wide, shell thickness 0.035 m, beam axis z=0.0675 m and bottom arm z=-0.05 m. Thus shell top and beam bottom meet at z=0.0175 m. Both use the same E, nu, G and generalized EA, GAy/GAz, GJ, EIy/EIz; global-y section direction is explicit. Shell connectivity/node order, all shell root coordinates, beam root first five coordinates, free normal spin, and physical tip loads Fy=100 N/Mz=10 Nm are checked. The native member count/retained variables and external Timoshenko interpolation differ; matching section parameters does not make their operators identical.

The external three translation rows are bottom-beam minus top-shell displacement; the two director rows are relative rx/ry, with no rz column. With rb=-0.05 and rs=0.0175, their arm coefficients agree with omega cross arm. Positive edge interpolation weights sum to one. Six infinitesimal rigid modes, the reference gap, a released beam normal spin, common finite rigid pose, and a central-difference virgin derivative probe support the specified five-channel linear law. The finite-pose probe is a control of the reference functional, not a finite native constitutive or trace acceptance. The derivative probe is one declared mixed direction; worst recorded error is 4.0590e-10 against its separate 1e-6 criterion. It should not be included in the claim that *all* controls are <=3.14e-12. The latter bound applies to recovered physical predicates (Fy 2.6072e-12, Mz 3.1363e-12).

Recovery uses recorded element resisting G, not unverified nodeReaction. On every nonroot beam station, the invertible five-column block reconstructs C_b^T mu=L-G; rz remains a separately checked free equilibrium equation. Connection loads exerted on domains are -C^T mu. Ground exerted loads are (G+C^T mu-L) restricted to prescribed components. This sign gives G=L+connection_exerted+ground, internal work equals those load works, and noncompatible virtual exerted work is minus multiplier-gap work. Independent force/arm formulas and complete domain cuts check the same convention. No external root station equation is present: the beam root is directly grounded in its first five coordinates. Positive-x interpolation can still exert loads on fixed shell root nodes; root G alone is not ground. The collector compares ground roles under the declared direct supports, not an old root-to-shell tie partition.

Native rigid virtual-work maps use one common beam-root origin. They include omega in every nodal rotation **and both retained cell rotations per member**, zero in retained resultants. This is necessary: nodal beam torque sums alone omit retained-cell covectors. Native physical transfer reconstructs spatial force, director couple, force-arm moments and zero-lift pullback independently, and checks against -C^T lambda. Native physical predicates are <=9.5267e-13. This supports signs/work bookkeeping; it does not establish drilling independence of either shell operator. Zero drilling/normal-spin columns in the line law do not remove shell stabilization from the mechanics.

## What the comparison measures

External transfer is a nodal atomic measure; native transfer is integrated P0 density on eight c2 supports spanning four halfcells/two shell intervals each. Their multipliers and pointwise station values are not interchangeable. Zeroth/first/second wrench moments about the same beam root are legitimate common measures: native wrench density is affine on each straight halfcell, so two Gauss points exactly integrate x^p times that density through p=2. For the quartic smooth window on [0.25,0.75], the collector uses three Gauss points (degree-five exactness), not the original two. Native cut boundaries align with halfcells; it has zero endpoint atoms. External open, closed and endpoint-atom windows are all retained, with closed-open=endpoint_atoms (checked for Mz component in both cases). Endpoint atoms are large: for the Mz load, external regional Mz is +15.9234 Nm open versus -6.28047 Nm closed, while the endpoint contribution is -22.2039 Nm. A chosen sharp-cut convention cannot be treated as a pointwise transfer error. Smooth regional Mz is 1.421665 Nm external versus 1.483540 Nm native; this avoids the endpoint jump but remains a fixed-discretization measure.

Common nodal shell Q1/beam P1 pose-field L2 integration is exact for the declared affine rectangular cells. Rotations are infinitesimal nodal orientations, not identification of external nodal rotations with native retained cell rotations. Translation/rotation component integrals are preserved, and the combined field uses the declared 1 m scaling; it is not a proven mechanics error norm. Applied work is q^T L (twice elastic strain energy in a linear equilibrium); the signed discrepancy uses the external work magnitude with the disclosed 1e-12 J floor.

## Disposition and next discriminator

No consequential sign, root-role, retained-variable, window-integration or field-integration defect was found in this bounded review. Preserve the discrepancy as a real fixed-mesh response difference. It has **not** been causally allocated to physical law, enforcement resolution, shell formulation or beam formulation: strong 160 nodal rows versus weak 40 density rows, ASDShellQ4 versus native Q4, and Timoshenko versus retained B3 all change together. A small equilibrium residual proves each discrete problem was solved, not that either is physical truth or within 1%.

One prospective discriminator, rather than an automatic mesh campaign, is to keep the external geometry/elements/materials/supports/load and assembled mechanics unchanged and replace only its strong station rows by work-conjugate c2 P0 integrated rows on the same eight physical supports. Predeclare exact P1/Q1 integration, arm/director channel maps and sign/rigid/work controls; compare Mz work and the same smooth/moment measures against the retained strong run and native run. This isolates *external enforcement-space sensitivity* while leaving its mechanical operators fixed. If the difference largely closes, that supports an enforcement-resolution explanation in that controlled model; if it persists, the remaining discrepancy still needs beam/shell same-state operator allocation. Neither outcome alone validates the native law or assigns all residual difference. Such a check needs separate execution authorization and effective runtime control; it was not run here.

External numerical thread count is unverified: the original runs request one OpenBLAS/MKL/OMP thread, and the separate ops.getNumThreads check returned None. Retained process observations are not an effective-thread/resource-performance pass. Native target-process BLAS/Numba=1 and JIT-disabled checks are recorded; those cannot repair the external gap. Mandatory independent CalculiX comparison, full convergence/accuracy, locking/drilling/torque qualification and F03 authority remain pending and unconsumed.
