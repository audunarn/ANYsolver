# Nodal rigid footprints — experimental delivery, 1 October 2026

Implemented: selected shell nodes follow one native beam node through the
existing objective six-row relative-pose law. Declared patches must select all
vertices and use actual shared cell edges. Normal spin is locked. This is not
a distributing connection, continuous-area weld or BL5 line. Q4 uses explicit
full algorithmic pullback; mixed/all-S3 are admitted. Initial scope: elastic
shell/generalized-beam response, without weak lines.

The sparse owner performs one global solve/atomic acceptance. Ordered group
incidence, immutable identifiers, physical per-node transpose actions and group
wrenches share a common reference/current beam-port origin. Compensated lever-arm
contributions survive moment summation. No new element equation, constitutive
law, legacy default, physical tolerance or package version is introduced.

Nonempty footprints have distinct model-bound policies. Existing stable S3
translation arithmetic applies only to elastic S3 footprints; complete origin/
accepted generalized histories use established V9 framing with empty fibre
arrays. Nonzero plastic/accumulated history rejects atomically. Retained scales
follow native F6/M12 roles, correcting a preexisting station-wrench packing error
only for this new workflow. Unequal-weight controls expose false passes and
false rejects; work-conjugate unit changes preserve the corrected measure.
Empty owners retain historical scales/identities; their legacy normalization
limitation is documented, not silently corrected or newly qualified.

## Preserved failures and decision

Initial runs retain28/8 and33/3 pass/fail. Fixture repairs corrected readonly
inputs, all-S3 policy and translation-only finite-load admission. A fixed-load
diagnosis showed identical legacy expanded/new expanded/grouped S3 failures and
matrices/trial traces. Existing stable arithmetic resolved that cancellation
issue without changing budgets or element equations.

Artifact `d9b409dc...` passed43/46 but genuinely failed post-rebase successor
parity in Q4, mixed and all-S3. F10/M20-normalized native force differences were
`9.13027e-9`, `9.12930e-9`, `3.55114e-9`, above `1e-9`. These remain failures.
One Q4 four-branch discriminator found exact original/ordinary-restored successors
and exact rebased/rebased-restored successors. Across charts, poses differed
about `1.7e-15`, axial force `9.13e-8N`; stored state/origin histories showed no
loss. The diagnostic did not separately snapshot every predecessor array.
No narrow repair was justified; S3 stabilization is not a Q4 chart remedy.

Decision: admit reference-linear and nonrebased finite footprints. A separate
identity-bound policy rejects public rebase/chart-wrapped restore before mutation,
including correctly framed current-model envelopes. Ordinary restart passes its
unchanged criteria. Strict footprint chart transport/successor parity remain
mandatory open M4/F06 work, not waived tolerance or permanent programme removal.

Full F04, drilling/shear/thickness/torque qualification, distributing/physical
area footprints, plasticity, line combinations, off-node mapping, seams, external
references, scale, complete consumers and aggregate gates remain open. This is
tested experimental behavior, not M4/G2 acceptance or release. No overall
development/solver speedup is claimed.
