# F03 independent classical loaded-reference preflight

22 September 2026. This is bounded derivation and implementation work, **not** a frozen or executed scientific comparison, native coupling qualification, or an external-solver reference. F03 remains in progress, G0B open, and G1 barred.

The independent classical comparator now has an assembled plane-stress Q4/CST panel, an independently assembled quadratic-axial/Hermite-transverse/quadratic-rotation Timoshenko beam, a four-sample shell pose, exact segmented P0/P1 weak-line work, and a small sparse saddle solve. The beam root and outer shell x edges are fixed. There is no exact point row at either beam-line endpoint, in accordance with the endpoint-capacity derivation. The line operator freezes sample correspondence and splits beam, mortar, Q4 host and CST diagonal crossings. The physical line gap is `Cb qb - Cs qs`; yaw is multiplied by the registered `.46 m` length in its line channels.

Twenty-nine bounded tests pass for affine/rigid patches, one-sided host checks, direct non-rigid line work, hand-integrated P0/P1 axial moments, row rank on one small fixture, loaded smooth/sine cases on Q4/CST with both mortar laws, free equilibrium, weak compatibility, stored-energy identity, support-only reactions, global force/moment balance, and a continuous-field L2 gap quadrature check. These tests are code/mechanics preflight, not a convergence claim. In particular the coupled solver admits only `Ns≤8`, `Ny≤16`, `Nb≤16`, `Nm≤8`; its residual ratios are finite-system algebraic diagnostics rather than the final mixed-unit physical acceptance norms.

Independent read-only review of the initial line work found no blocker for the bounded straight planar operator. Review of the first loaded solver found doubled reported energies, a dimensionally mixed residual ratio, and reactions taken from all DOFs. Those findings were corrected before this record: energies are half the quadratic forms, free and weak residuals are separate, and only supported residual entries are returned as reactions. The hand-integrated axial mortar moments and support-only global balance tests were added in response. A final independent read-only recheck found **no blocker to committing this bounded preflight**, while explicitly leaving physical stability, norm definitions, certified gap extrema, refinement, and resources for separate registered work.
