# F03 retained-evidence cross-case components

23 September 2026. Source commit:
`1d4648be2a8754909a2324d53fe772443e85c4f3` on the isolated
`codex/b3-ge-e4-pl-integration` branch.

This patch provides the solve-free arithmetic, retained-snapshot reader and
five-case pairing adapter needed by the future F03 aggregate. It does **not**
provide the aggregate receipt writer or serial one-use coordinator, launch a
scientific case, decide the registered local-reference screen, or close G0B.

- The arithmetic checks the frozen 45 signed channels, two nested settling
  chains, four exact-prolongation/Ritz transitions, separate shell and beam
  Galerkin identities, load/root/trace operators and saved/common trace
  actions. It evaluates the complete signed functional difference at Green
  orders 48 and 64 with explicit resource preflights. Only `Q1_L2/Q2_L1` is
  the gating nonnested cross-family pair.
- The snapshot reader binds a passing independently replayed case receipt to
  one retained saved-evidence snapshot, registered plan ZIP, lifecycle,
  numerical and inverse indexes, saved functional input, and independently
  rederived exact topology interpolation. It reopens registration and source
  identities on entry and on normal or exceptional exit. Arithmetic inputs
  become owned read-only arrays.
- The registration source-role inventory now includes the three new modules,
  so a future immutable registration binds their exact bytes.

The final affected suite passed **88 tests**, with **one Windows symlink
privilege skip**, in 44.78 s. The independent reviewer ran a bounded set of
**40 passing tests**, with the same environmental skip, and reported no
remaining code or mechanics findings. Two review findings were closed before
commit: saved trace actions were added to the common-action check, and source
identity is rechecked even when comparison raises. Adversarial tests cover
changed actions, stale indexes, functional/receipt mismatches, a source swap,
wrong exact interpolation, and exceptional exits. No factorization,
equilibrium solve, element assembly or recovery call is in these modules.
