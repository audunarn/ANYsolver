# Q4 pressure-side patch development route

`Q4_S3_PATCH_GENERAL_NODAL_PRIMAL_MORTAR_PENALTY_STATIC_DEV_V0` admits one qualified planar-reference Q4 pressure face against two qualified S3 V2D target faces. The target faces may share material nodes. The Q4 keeps four nonnegative original Q1 numerical pressure functions; the S3 target is integrated as its physical P1 surface. The multi-control path has its own `Q4_S3_PATCH_GENERAL_NODAL_MULTI_CONTROL_PENALTY_PATH_DEV_V0` identity. This route is opt-in development, not C1 engineering acceptance.

The kernel clips projected four-corner polygons, then evaluates the physical bilinear source position and varying source normal at every quadrature point. It converts the projected integration area to the source reference-area measure pointwise using the actual Q4 Jacobians. The target position uses its original interpolation. A warped **current** Q4 trial is admitted from a planar qualified reference Q4; a warped reference Q4 requires its separate varying-frame formulation. No triangulated substitute defines source pressure or work.

The public `q4_source_area_tolerance` (m²), `q4_source_weighted_gap_tolerance` (m³), and `maximum_q4_source_integration_triangles` are required. An adaptive midpoint subdivision controls estimated support, pressure Gram, and weighted-gap integration errors; the estimates are reported separately. Exhausted quadrature or numerical differentiation budgets fail explicitly. The present tangent differentiates the aggregate scalar penalty energy over unique physical material nodes, which is expensive even for this small patch.

`Q4_S3_PATCH_GENERAL_NODAL_PRIMAL_MORTAR_AUGMENTED_STATIC_DEV_V0` additionally admits projected normal pressure on the same four original Q1 source functions. At held multipliers it differentiates weighted-gap virtual work, including changing overlap support, and uses a generally nonsymmetric contact tangent. It neither replaces the bilinear Q4 geometry with triangles nor treats the numerical multiplier as a shell stress. The opt-in multi-control path has a separate augmented profile identity. Ordinary force and displacement control admit this development profile. Q4/Q4 augmentation remains unadmitted.

For the Q4-source augmented profile, the static owners compute the expensive contact Hessian only on physical axes reached by free structural coordinates. They still compute the full contact residual for support reactions. A reduced-coordinate directional check matched the free-coordinate residual derivative with fewer than 300 geometry evaluations; the unrestricted full Hessian budget is 1,153 evaluations for this patch. This is a local count, not a measured whole-route speedup. A small loaded force-control case completed with active pressure, more than one multiplier update and a version-2 multiplier checkpoint in 45.72 seconds on the local host. With step growth disabled solely for the comparison, a split restart at load factor 0.5 followed the same 0.25, 0.5, 0.75, 1.0 increments as the uninterrupted solve and met the registered final displacement and multiplier tolerances. Adaptive histories that reached different intermediate factors produced different final values and were retained as failed comparison evidence. A warped-current-Q4 virtual-work check balanced force and moment and passed a smooth-branch tangent comparison.

A one-step path that prescribes one pressure-side corner 0.5 mm past first contact did **not** converge at the declared 0.02 Pa pressure-change tolerance. Equilibrium, the displacement constraint and the 5 mm independent gap budget passed, but the multiplier change decreased from about 0.388 Pa to only 0.111 Pa in 12 updates while the conservative lower gap moved to about −1.614 mm. The solver rejected the step and restored the accepted pose and multipliers. Increasing the augmentation count alone is not an accepted remedy for this under-resolved, overdriven case. The failure trace is retained under `q4-source-al-augmentation-trace.txt` in the evidence folder. A one-augmentation rollback case also passed. A separate 0.05 mm prescribed-corner closure under ordinary displacement control activated Q1 pressure, required a multiplier update, balanced both bodies' forces and passed a matched-half-step restart comparison (`q4-source-al-displacement-restart-first.txt`, 129.79 s).

At the same 0.05 mm closure, a four-phase Q4-source augmented path pressed, slid 50 mm, opened and recontacted. All phases met the declared 5 mm gap budget and pair-force balance; opening released all four multipliers. A checkpoint after opening resumed through recontact with final displacement and multipliers matching the uninterrupted path (`q4-source-al-four-phase-restart-first.txt`, 249.94 s). The earlier 0.5 mm overdriven case remains failed evidence. Tight-gap and pressure-space convergence, full-route resource accounting, independent acceptance and installed-package verification for this new profile remain open.

The runnable [augmented Q4/S3 example](../examples/general_contact_q4_s3_augmented_path.py) uses this small-closure path and prints each phase's independent lower gap, normal force, multiplier vector and augmentation count. Run it with this checkout's `src` directory on `PYTHONPATH`, or against an installed package whose import origin has been checked. The first source run completed with four active pressure DOFs on contact phases, zero pressure on opening, final recontact normal force about 0.0849 N and checkpoint schema version 2 (`q4-source-al-example-source-final.txt`). A wheel built from commit `3b348f20` with SHA-256 `1237aba563100dfa5956626c55a99c5e470d5a236c506d82841481921907cb8e` was installed without network dependencies into an isolated target. The import origin pointed into that target, and the installed example output exactly matched the source output (`q4-source-al-example-installed-3b348f20.txt`, output SHA-256 `b9d0afb610d00120afb78f892764cf0e421e7796caf66a506ad7331fca458ac`). The package was not published.

The independent physical gap uses a conservative cone of the Q4's four bilinear corner normals and all source–target vertex differences. A corresponding swept normal cone covers linear nodal trial paths. These bounds can reject safe warped poses; unresolved paths cut back or fail. They are not pointwise mortar constraints.

The runnable [general_contact_q4_s3_patch_path.py](../examples/general_contact_q4_s3_patch_path.py) uses a nonmatching Q4/two-S3 pair with a permissive 20 mm gap budget and soft pressure penalty. Its source run completed press, 50 mm slide, open and recontact. All four Q1 pressure DOFs were active in the contact phases; the open phase had zero contact force. The conservative lower gap reached about −8.13 mm, the integrated normal reaction about 2.9 N, and the reported weighted-gap integration estimate stayed below 6.2×10⁻¹³ m³. These settings exercise the route and are not engineering recommendations.

Local penalty evidence covers constant pressure, full Q1 Gram rank, an independently integrated warped-Q4 case, balanced pair work, a warped-trial smooth-branch tangent action check at relative error ≤10⁻⁵, direct coupled static assembly, and a four-phase path with midpoint restart. The latter took 563.93 seconds with the current numerical Hessian. An isolated wheel built from source commit `4876909b` reproduced the source four-phase example byte for byte. Tight independent gap, Q4–Q4 augmentation, pressure-space convergence, friction, native beams and impact remain separate gates. The full C0–C9 programme remains open.
