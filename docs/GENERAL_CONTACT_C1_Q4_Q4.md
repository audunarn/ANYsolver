# Explicit Q4/Q4 general contact development route

`Q4_Q4_GENERAL_NODAL_PRIMAL_MORTAR_PENALTY_STATIC_DEV_V0` admits one explicitly paired qualified planar-reference Q4 shell face per body. The named source supplies four nonnegative original Q1 numerical pressure functions. Both bodies retain their original bilinear physical skins, declared sides, thickness offsets and nodal work maps. Warped current Q4 trial geometry is evaluated; warped reference Q4 geometry remains a separate formulation route. This is an opt-in development profile, not C1 engineering acceptance.

Projected overlap clips the four-corner boundaries. At each integration point the kernel evaluates physical Q1 source and target positions, the source's varying normal, and pointwise conversion to the source reference-area measure. Support, weighted gap and pressure Gram are integrated with explicit dimensional area and weighted-gap error controls plus a finite triangle budget. The scalar penalty energy is differentiated over the eight physical material nodes, with a finite energy-evaluation cap. The present numerical Hessian is expensive and limits this profile to small scenes.

The independent physical-gap gate bounds every represented source–target point pair using the convex cone of four Q4 source corner normals. Swept Bernstein controls along the linear nodal trial path cut back unresolved or crossing steps. These conservative bounds may reject safe poses. Weak mortar consistency does not prove tight pointwise nonpenetration.

The [general_contact_q4_q4_path.py](../examples/general_contact_q4_q4_path.py) example presses, slides 50 mm, opens and recontacts two nonmatching physical Q4 skins using a permissive 20 mm gap tolerance and a soft penalty. The source run completed with 4/4/0/4 active Q1 pressure DOFs, conservative lower gaps about −8.13/−8.11/+15/−8.11 mm, and normal reactions about 2.92/2.82/0/2.82 N. Reported weighted-gap integration estimates stayed below 7.4×10⁻¹³ m³. Those controls are development settings, not engineering recommendations.

Local evidence includes an independent Q4/Q4 bilinear-target gap integral and balanced work, a coupled warped-target static check, crossing rejection, and a four-phase path with midpoint restart (322.82 seconds with the current numerical Hessian).
