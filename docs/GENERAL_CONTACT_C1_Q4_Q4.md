# Explicit Q4/Q4 general contact development route

`Q4_Q4_GENERAL_NODAL_PRIMAL_MORTAR_PENALTY_STATIC_DEV_V0` admits one explicitly paired qualified planar-reference Q4 shell face per body. The named source supplies four nonnegative original Q1 numerical pressure functions. Both bodies retain their original bilinear physical skins, declared sides, thickness offsets and nodal work maps. Warped current Q4 trial geometry is evaluated; warped reference Q4 geometry remains a separate formulation route. This is an opt-in development profile, not C1 engineering acceptance.

Projected overlap clips the four-corner boundaries. At each integration point the kernel evaluates physical Q1 source and target positions, the source's varying normal, and pointwise conversion to the source reference-area measure. Support, weighted gap and pressure Gram are integrated with explicit dimensional area and weighted-gap error controls plus a finite triangle budget. The scalar penalty energy is differentiated over the eight physical material nodes, with a finite energy-evaluation cap. The present numerical Hessian is expensive and limits this profile to small scenes.

The independent physical-gap gate bounds every represented source–target point pair using the convex cone of four Q4 source corner normals. Swept Bernstein controls along the linear nodal trial path cut back unresolved or crossing steps. These conservative bounds may reject safe poses. Weak mortar consistency does not prove tight pointwise nonpenetration.

The [general_contact_q4_q4_path.py](../examples/general_contact_q4_q4_path.py) example presses, slides 50 mm, opens and recontacts two nonmatching physical Q4 skins using a permissive 20 mm gap tolerance and a soft penalty. The source run completed with 4/4/0/4 active Q1 pressure DOFs, conservative lower gaps about −8.13/−8.11/+15/−8.11 mm, and normal reactions about 2.92/2.82/0/2.82 N. Reported weighted-gap integration estimates stayed below 7.4×10⁻¹³ m³. Those controls are development settings, not engineering recommendations.

Local penalty evidence includes an independent Q4/Q4 bilinear-target gap integral and balanced work, a coupled warped-target static check, crossing rejection, and a four-phase path with midpoint restart (322.82 seconds with the current numerical Hessian). An isolated wheel built from source commit `4826bba2` reproduced the source example byte for byte.

`Q4_Q4_GENERAL_NODAL_PRIMAL_MORTAR_AUGMENTED_STATIC_DEV_V0` is a separate opt-in projected-normal development profile on the same explicit Q4/Q4 geometry. The source uses four original nonnegative Q1 pressure functions. At held multipliers, the law differentiates weighted-gap virtual work, including changing overlap support, and uses a generally nonsymmetric contact tangent. The public multi-control path has its own `Q4_Q4_PATCH_GENERAL_AUGMENTED_PATH_DEV_V0` identity. It retains the same physical gap, swept and integration budgets as the penalty pair.

Local augmented checks passed zero-gap pressure, opening projection, warped-current force/moment balance, a smooth-branch tangent comparison, public reduced-coordinate tangent and a small-closure four-phase path with 50 mm sliding. The opening phase released all multipliers. A checkpoint after opening resumed through recontact with final displacement and multipliers matching the uninterrupted path (`q4-pair-al-path-restart-first.txt`, 141.65 s). Ordinary force and displacement control also passed small-closure active-pressure, multiplier-update and both-body force checks. Both routes passed split-restart final displacement and multiplier comparisons (`q4-pair-al-ordinary-restart-first.txt`, 145.96 s); the force comparison used fixed 0.25 load increments to match the accepted path. These are 0.05 mm corner-closure development cases with a 5 mm independent gap budget and 0.02 Pa pressure-change tolerance. Pressure-space stability, tight enforcement, Q4/S3 role-exchange convergence, reference-warped Q4, installed-package verification of the augmented profile, friction, native beams and impact remain open. The full C0–C9 programme remains open.

The runnable [augmented Q4/Q4 example](../examples/general_contact_q4_q4_augmented_path.py) prints the phase activity, independent lower gap, normal force, multiplier vector and update count. Its checked source run completed with zero multipliers on opening, final recontact normal force about 0.0849 N, conservative lower gap about −0.143 mm and checkpoint schema version 2 (`q4-pair-al-example-source-first.txt`). A wheel built from commit `03e29a14` with SHA-256 `f761b89dde89455085c38ae5730503f7243cfd4cde5fb34288c1ec197c2bb553` was installed without network dependencies into an isolated target. The import origin pointed into that target; the installed example output matched the source output byte for byte (`q4-pair-al-example-installed-03e29a14.txt`, output SHA-256 `28108f412b241aa8a7c63752a40e899371fbe00fa9fdc2f6e49a3d8bef230242`). The package was not published.

A separate single-press exploration raised the normal stiffness from 1,000 to 10,000 Pa/m and required an independent lower gap within 0.05 mm, equal to 10⁻³ of the 50 mm shell thickness. It failed at the 15-iteration limit; allowing 40 iterations ended in explicit `contact_gap_exceeded` rather than an accepted physical state (`q4-pair-al-tight-gap-10x-first.txt`, `q4-pair-al-tight-gap-10x-40iter.txt`). A focused regression confirms rollback of coordinates and multipliers on that rejection (`q4-pair-al-tight-gap-10x-rejection-final.txt`). This single stiffness change is not an enforcement or mesh-convergence study; the 0.05 mm benchmark remains unqualified.

A separate geometry diagnostic evaluated the current conservative bound at two prescribed poses (`q4-pair-al-gap-bound-oracle.py`, `q4-pair-al-gap-bound-oracle.txt`). Moving only one source corner by 15.05 mm gave a bound of −18.114 mm while the kernel's sampled minimum was −0.05001 mm. Uniformly moving all four source corners by the same amount gave a bound and sampled minimum both near −0.05000 mm. The sampled minimum is not a continuous gap certificate. The difference shows that the existing whole-face normal-cone bound can become very loose under Q4 warping; a tighter certified overlap-local bound is needed before the 0.05 mm gate can be adjudicated from these runs.

An opt-in [projected-gap V1 development profile](GENERAL_CONTACT_C1_Q4_PROJECTED_GAP.md) now has separate static/path and restart identities. It uses a matching-projection lower bound with a swept normal-cone guard. Small-closure force/displacement and four-phase restart checks passed at a 0.2 mm declared gap; one 0.04 mm closure met a 0.05 mm independent gap budget with 10× normal stiffness. This does not change the V0 result above or establish enforcement/mesh convergence.
